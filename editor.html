Слева выберите товар → справа измените → нажмите «Сохранить». Через 1–2 минуты изменения появятся на сайте.

Это пароль для сохранения. Хранится только в вашем браузере, на сайт его никто не видит.

Как получить ключ:

  1. Откройте страницу токенов GitHub
  2. Создайте токен → репозиторий samsara-store
  3. Право Contents → Read and write
  4. Скопируйте и вставьте сюда

Не отправляйте ключ никому и не вставляйте его в чат.
