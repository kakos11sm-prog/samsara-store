Доступ к сохранению

Один раз вставьте GitHub token с правом писать в репозиторий samsara-store. Он хранится только в вашем браузере.

  1. Откройте Fine-grained tokens
  2. Generate → выберите только репозиторий samsara-store
  3. Permissions → Repository → Contents: Read and write
  4. Скопируйте token и вставьте ниже
